# 当前 Base 的骨架与功能块

## 极简骨架

- 理解用户的真实目标、当前背景、期望结果和边界。
- 在授权范围内自主推进，交付正确、完整、可用且经过相称验证的结果。
- 需要用户决定、授权或外部协调时停止并说明。
- 使用足以指导行动的背景事实和少量直接规则，不预先枚举所有情境。

## 固定模块

- 用户沟通频道和最终交付格式。
- PowerShell、Windows 路径和文件编辑规则。
- 权限、破坏性操作、外部状态变化和真实验证。
- Skill 选择与运行时加载机制。
- 当前已注册角色、模型成本和 `fork_turns` 平台事实。

这些内容涉及宿主机制、环境约束或难以通过普通样本安全覆盖的边界，本轮不因没有触发失败而删除。

## 当前候选功能块

### 多代理阶段所有权

触发：任务能够可靠交接，并需要多轮工具调用或会带入大量材料。

行动：把完整阶段交给合适角色；每项责任只有一个所有者；Root 停止该阶段，没有其他工作时调用 `wait_agent`。

结果：Root 保持整体路径和判断上下文，下级连续完成执行，报告返回后再安排后续。

### 上下文复用

触发：后续工作能够利用已完成代理的相关理解。

行动：使用 `followup_task`；无关上下文会干扰判断时创建新代理。

### 报告信任

触发：subagent 已提交证据和验证充分的完整报告。

行动：默认采信；只有具体矛盾、会改变结论的缺口或较高错误代价才定向核验。

### 浏览器阶段所有权

触发：任务需要真实页面交互。

行动：把整个浏览器阶段交给一个 `browser-operator` 连续完成。

## 恢复规则库中的候选块

- 独立阶段并行、强依赖和共享修改范围的详细判断。
- `fork_turns` 的完整合同构成与无关上下文说明。
- followup 复用中“应用既定做法”和“重新判断方案”的细分。
- 线程额度用途与浏览器逐步接管的明确反例。
- 委派不扩大权限的重复提醒。

这些内容当前不进入极简候选；对应测试出现稳定退化时再按完整功能块恢复。
