# Prompt Architecture

这个目录说明当前 Root Base 的支撑结构和发布关系，不保存第二份运行正文，也不保存待部署候选。

## 当前材料

- `../codex_base_instruction_5.6.md` 是 Root Base 的公开发行权威正文。
- `../evolution-map.md` 按行为和功能块记录公开版本的规则演变、迁移、否决和验证层次。
- `../functional-block-baseline.md` 是当前功能块的保真基线和快速比较入口，只提供局部检查起点，不是完整验收基线。
- `functional-block-map.md` 将当前功能块映射到 Root Base、全局共同规则、角色提示词或 Skill 等实际承载层。
- `runtime-loading-and-release.md` 说明权威源、运行时镜像、加载层和发布边界。
- `test-results.md` 是已经完成的实验记录；其中的候选、字数和结论只代表当时实验，不能当作当前架构。

## 结构原则

Root Base 与每个可维护的提示词块都先说明目的和原则，再收敛到责任与决定权限、路线与阶段、具体行动与工具，最后说明验证、交回和例外。每一层细化上一层，不能改变上位规则的结果或权限。功能块地图用于检查规则是否处在正确层；它不要求历史材料或实验记录按运行正文的章节顺序重写。

修改架构说明时，先确认规则的真实加载层。只有当前 Root 必须持续判断的内容才留在 Root Base；所有责任层共同需要的执行规则属于全局 `AGENTS.md`，角色内部职责属于角色提示词，领域方法属于相应 Skill，平台参数和宿主行为以当前配置与工具说明为准。
