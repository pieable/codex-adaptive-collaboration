# 本机额外 Skill 的来源与维护状态

本文件不参与运行。它记录本机额外 Skill 的来源，以及本轮从安装副本迁入公开仓库的状态，防止安装状态被误当作用户已经确认的发行状态。

## `company-research-brief`

- **来源：** 用户为风投同事准备的专门 Skill；本机目录包含 2026-06 至 2026-08 的多份命名备份、行业框架、来源政策和报告模板。
- **当前状态：** `current-effective + unverified`；2026-08-30 已在公开仓库形成重新定义稿并同步当前运行副本。
- **当前判断：** 旧安装版不再作为正确基线；新稿按风投同事的真实用途重建，以“支持什么投资决定”为入口，把产品线比较、商业化阶段、来源分层和当前处理意见设为主干。旧版中仍有效的来源、市场、比较和报告资料按历史核对后复用。
- **保留价值：** 继续保护事实/自述/第三方线索/推断边界，避免把 BP、官网、新闻稿和创始人表述直接升级为客户、订单、收入、技术领先或商业化质量事实；新增按产品线区分直接竞品、替代路线、成熟标杆和上下游参照。
- **处理方式：** 公开目录包含新 `SKILL.md`、逐条 `RULE_RATIONALE.md`、六个维护评测案例、UI 元数据、五份运行 references 和两份 assets，不带入历史备份、固定字数、固定标题、强制 report-writer、DeepSeek 润色或固定 Word 样式。真实同事使用效果仍需后续任务观察。
- **来源位置：** 公开 `skills/company-research-brief/` 为版本权威；本机同名运行目录已经逐文件同步，目录中的旧命名备份继续只作历史证据；私人 Prompt Lab 保存公司研究路由记录。

## `search-source-registry`

- **来源：** 用户为各类网络搜索 Agent 维护的通用搜索入口和信源注册表；本机有命名备份、`references/`、`scripts/` 和来源实验记录。
- **当前状态：** `current-effective + unverified`；2026-08-30 已从本机权威候选纳入公开仓库
- **目的：** 预先告诉 Agent 不同问题适合从哪些权威来源开始、在哪里枚举候选以及怎样保存覆盖缺口，减少临时摸索，使搜索更快、召回更完整、证据更可靠。
- **现有价值：** 按主张选择最接近原始记录的来源，先枚举候选再核验；保存入口失败、登录、浏览器依赖和未检查状态，不能把“没有找到”写成“没有发生”。
- **历史案例：** C-13；SEC EDGAR 枚举找回早期漏掉候选，并保留 403 和超时缺口。
- **处理方式：** 已核对本机正文、四份命名备份、references、scripts 和实验记录；公开发行包含当前运行文件和 `RULE_RATIONALE.md`，不包含历史备份。静态结构和脚本入口已经验证，真实网络来源覆盖尚未重验。
