# `code-review` 规则理由

本文件不参与运行。

## CR-01 Reviewer 只判断提交给它的准确候选

- **状态：** `current-effective`
- **行为：** 评审对象、基线、期望结果、约束、实际差异和验证证据必须明确；Reviewer 不决定用户目标、产品路线或整个任务是否完成。
- **理由：** Reviewer 获得的是局部合入判断权。没有准确候选或合同，它无法区分实现错误、需求争议和证据缺失。
- **案例：** C-15。
- **来源：** `SKILL.md`“评审责任”“评审过程”；`agents/PROMPT_HISTORY.md` 2026-08-29；Git `86b6468`。
- **验证：** 静态合同完整；真实闭环待验证。
- **改变条件：** 上级改变合同后必须按新合同重新评审，Reviewer 不自行改合同。

## CR-02 结论必须是可合入、要求修改或证据不足

- **状态：** `current-effective + unverified`
- **行为：** 无阻塞问题且证据支持声明才可合入；合同未满足或候选不安全则要求修改；对象、实现或证据不足则明确证据不足。后两者不能当通过。
- **理由：** 旧 Reviewer 只有问题清单，无法区分“没发现问题”和“没有能力证明”。明确结论让阶段负责人知道下一步。
- **案例：** C-15。
- **来源：** `SKILL.md`“评审结论”；`agents/PROMPT_HISTORY.md`；DeepSeek Harness `dsh-code-review` 的公开思路。
- **验证：** 文字静态明确；三条真实路径尚未系统验收。
- **改变条件：** 可以改用户可见措辞，但必须保留三种不同后果。

## CR-03 从实际后果生成风险面，不机械扫固定清单

- **状态：** `current-effective`
- **行为：** 根据候选触及的调用关系、异步生命周期、接口权限、状态缓存、prompt/schema、真实入口、边界、文案和复杂度选择检查方向。
- **理由：** 风险方向是开放现实的例子，不是每次都要填完的表。真正需要的是沿变更可能产生的后果定向补查。
- **案例：** C-07、C-14。
- **来源：** `SKILL.md`“从风险面检查”；`write-instructions-zh` 的开放现实/有界清单规则。
- **验证：** 结构审查通过；不同代码类型仍靠 Reviewer 判断。
- **改变条件：** 安全或固定协议中遗漏具体项会造成重大损失时，可以保留明确有界清单。

## CR-04 证据层必须覆盖合入声明

- **状态：** `current-effective`
- **行为：** 对模型实际收到的 prompt、schema、结果和诊断，或真实宿主、权限和外部服务，必须检查对应层的证据；低层静态通过不能升级。
- **理由：** 代码本身正确不等于实际入口加载，也不等于用户流程成立。
- **案例：** C-04、C-14。
- **来源：** `SKILL.md`“检查证据强度”；全局验证责任。
- **验证：** 规则存在；仓库尚无覆盖全部机制的真实评审快照。
- **改变条件：** 新自动化只能替代其真实覆盖的层次。

## CR-05 Reviewer 只读并报告可操作机制，不写补丁

- **状态：** `current-effective`
- **行为：** 报告事实、触发条件、影响和需要纠正的机制；不修改候选、不写补丁、不替上级重定路线。
- **理由：** 独立性要求评审者与实现者分离。Reviewer 写补丁会混淆发现问题、改变候选和重新验收三种责任。
- **来源：** `SKILL.md`“评审边界”；`MODIFICATION_LOG.md` 2026-08-25。
- **验证：** 静态只读边界明确；真实角色权限待宿主验证。
- **改变条件：** 修复应交回实现负责人；若未来需要“评审并修复”应创建另一种角色，而不是暗改 Reviewer。

## CR-06 复杂度只审查本次变更新增的维护成本

- **状态：** `current-effective`
- **行为：** 判断候选是否引入无当前结果支撑的结构、配置、抽象或依赖；不把评审扩大成整个仓库重构建议。
- **理由：** Reviewer 应阻止本次变更制造新负担，但没有权限借评审重设计既有系统。
- **来源：** `MODIFICATION_LOG.md` 2026-08-25；`SKILL.md` 风险方向。
- **验证：** 静态规则存在；真实评审行为未验证。
- **改变条件：** 既有问题只有在候选新产生、放大或暴露为阻塞时才报告。
