# `deep-research` 规则理由

本文件不参与运行。该 Skill 过去没有自己的修改日志，本文件先把 Git 和 Prompt Lab 中分散的理由恢复出来。

## DR-01 只在开放、模糊或单次查询不足时触发

- **状态：** `current-effective`
- **行为：** 任务需要先调查才能形成问题/路线、当前陷入困境缺少换路依据，或准确结论需要多来源核验时使用；封闭且一次权威查询足够的简单事实不使用。
- **理由：** 深研成本高，不能把所有事实查询升级成研究项目；但已有可写答案也不能成为开放问题过早停止的理由。
- **来源：** `SKILL.md` description 和开头；初始提交 `6a25aa8`。
- **验证：** 静态触发条件明确；真实任务触发精度待观察。
- **改变条件：** 任务空间、证据要求或路线不确定性改变时重新判断，不以篇幅决定。

## DR-02 Root、Lead 和取证执行者分工

- **状态：** `current-effective + unverified`
- **行为：** 单条封闭网络取证直接交 Web Researcher；多路线研究由 Research Lead 组织；网络发现和路线核验由 Web Researcher，本地原始材料由 Explorer，上层负责结构、冲突和综合。
- **理由：** “重要结论应亲自接触一手资料”曾诱发 Root/Lead 自己搜索，挤占整体判断并重复执行。上层只对已经定位且会改变判断的具体矛盾读取最小原文。
- **案例：** C-11、C-13。
- **来源：** `SKILL.md`“责任分工”；Git `aea9980`；`agents/PROMPT_HISTORY.md` 2026-08-29；`subagent-architecture/rule-rationale.md` R34。
- **验证：** 静态角色路由清楚；完整研究闭环待验证。
- **改变条件：** 只有具体来源矛盾无法由报告解释时，上层做最小核验，不扩展成新搜索路线。

## DR-03 从研究原点建立覆盖结构

- **状态：** `current-effective`
- **行为：** 明确当前主张、时间关系、候选、来源系统、竞争解释和未知；陌生领域先用权威教材、手册或综述建立术语与边界，再追一手材料。
- **理由：** 没有覆盖结构时，搜索容易围绕第一条线索堆材料，既漏候选也无法说明结论边界。
- **案例：** C-13。
- **来源：** `SKILL.md`“建立研究原点”；`search-source-registry`。
- **验证：** 来源召回案例支持；不同领域的结构仍需按问题调整。
- **改变条件：** 对象封闭且术语明确的一手取证不需要先读综述；不能机械化为固定步骤。

## DR-04 发散和收敛根据新证据自适应

- **状态：** `current-effective + conditional`
- **行为：** 搜索结果产生新候选、反例、术语和来源入口后更新路线；大型开放研究至少有一次由上一轮结果驱动的后续搜索。新增独立路线很少改变结论时收敛。
- **理由：** 一次固定搜索无法发现第二层入口；同时“多轮”不能变成固定轮数和无休止扩张。
- **案例：** C-13；EDGAR 枚举找回早期漏掉候选。
- **来源：** `SKILL.md`“发散与收敛”；Git `22d1993`。
- **验证：** 历史搜索实验支持；完整联网基准缺失。
- **改变条件：** 用户停止、来源不可达或对象封闭时可不做后续搜索，并记录未覆盖范围。

## DR-05 来源只能支持它直接记载的内容

- **状态：** `current-effective`
- **行为：** 保存来源、日期、主张、冲突和覆盖；区分公司自述、第三方线索、权威记录和推断。入口失败、403、超时和未检查状态不能被写成“没有发生”。
- **理由：** 工具调用成功不等于覆盖完整，BP/新闻稿也不能自动升级成客户、收入或技术领先事实。
- **案例：** C-13。
- **来源：** `SKILL.md`“核验与交付”；`search-source-registry`；`company-research-brief`。
- **验证：** 半导体来源召回案例直接支持；其他领域待验证。
- **改变条件：** 来源等级随主张类型变化，不建立跨领域固定网站白名单。

## DR-06 程序承担机械处理，不替模型作相关性和结论判断

- **状态：** `current-effective`
- **行为：** 抓取、过滤、去重、重试、限额和记录可交程序；候选相关性、完整性、冲突解释和采用结论由负责判断的模型完成。
- **理由：** 自动化适合稳定重复工作，但会把错误筛选规则批量放大，且不能仅凭返回数量判断研究质量。
- **来源：** `subagent-architecture/rule-rationale.md` R16；`batch-execution`。
- **验证：** 历史搜索实验支持边界。
- **改变条件：** 只有经过代表性案例验证的有界分类可机械化，并保留抽样和缺口证据。

## 保护说明

- “至少一次结果驱动的后续搜索”只适用于大型开放研究，不是所有网络查询的固定轮数。
- “先读综述”只用于陌生领域建立结构，不能凌驾封闭一手取证。
- 本 Skill 没有旧版 `MODIFICATION_LOG.md`；Git `6a25aa8`、`22d1993`、`aea9980` 和 Prompt Lab 是当前主要历史来源。
