# 通用信源等级与搜索路线

没有领域专用来源表时使用本指导。先写清要核验的主张，再判断来源等级；不要给网站永久贴等级。同一来源对不同主张的证明力可能不同。

## 信源等级

| 等级 | 能做什么 | 常见来源 | 使用限制 |
| --- | --- | --- | --- |
| 一级：直接记录 | 直接证明某个事实、数据、规则或行为 | 法规和法院文书、监管或交易所披露、官方统计及方法说明、标准正文、产品文档和更新记录、源码、原始论文与数据、当事方原始声明 | 当事方材料能证明“它说了什么、做了什么”，不能自动证明其解释客观或效果最佳 |
| 二级：独立核验 | 独立调查、复核或解释一级材料 | 有编辑与更正机制的新闻机构、系统综述、专业机构报告、公开方法和引用链的研究 | 检查作者、方法、引用材料、发布日期和利益关系；结论不能超出其样本和范围 |
| 三级：可追溯整理 | 汇总背景、解释概念并提供上游线索 | 专业媒体、行业文章、机构博客、百科、署名专家文章 | 用于理解和发现关键词；重要主张沿链接追到一级或二级材料 |
| 四级：待核线索 | 提供候选、传闻、个体经验或搜索线索 | 聚合页、转载、搜索摘要、匿名帖子、论坛、社交媒体、无引用的 AI 摘要 | 不能单独支持事实结论；只有研究“有人如何评价或经历”时，原帖才是相应的一手材料 |

来源等级由当前主张决定。例如，产品官网对“标称参数”是一级，对“实际体验”不是；用户评论对“这名用户报告了什么”是一级，对“所有用户都会怎样”不是。

## 先找哪种原始记录

| 要核验的主张 | 先找的一级材料 | 必查边界 |
| --- | --- | --- |
| 产品功能、价格、可用性 | 官方产品页、文档、定价页、更新记录、状态页 | 版本、地区、账户类型、查询日期 |
| 法律、政策、司法决定 | 立法或监管机关正式发布、政府公报、法院文书 | 管辖地、生效日期、修订或废止状态 |
| 人物职务、组织关系 | 组织名录、任免公告、监管披露、本人或机构原始声明 | 任职起止时间、同名对象、法律实体 |
| 公司与财务数据 | 交易所和监管披露、财报、招股书、工商登记、投资者关系材料 | 报告期、主体、币种、指标口径 |
| 学术或技术结论 | 原始论文、数据集、代码、实验方案、勘误或撤稿记录 | 版本、样本、方法、复现状态 |
| 统计与经济指标 | 指标生产机构的数据集和方法说明 | 定义、统计期、修订、是否季调 |
| 新闻事件 | 公告、文件、讲话、记录等事件源头，再用独立报道补背景 | 事件发生日期与报道发布日期 |
| 健康、安全等高风险判断 | 监管机构、公共卫生机构、专业指南、系统综述和原始研究 | 适用人群、地区、证据等级、更新日期 |
| 地点、营业和交通状态 | 场所或运营方页面、政府或交通机构公告 | 地点、日期、临时变更；体验判断另查近期独立材料 |

## 搜索路线

1. 把问题改写成可核验的主张，写出对象、时间或版本、地区和所需覆盖范围。
2. 判断谁或哪个系统会产生这条主张的原始记录，并搜索“对象 + 文件类型或机构名”，而不是只搜索问题原句。已知发布方时使用官网域名、站内搜索或数据库筛选。
3. 先打开一级材料。找不到时，用二级、三级和四级来源发现正式名称、文件编号、作者、日期和原始链接，再沿引用链向上查。
4. 逐条记录来源实际证明了什么。搜索摘要、转述标题和引用片段只用于定位，不能代替打开原文。
5. 出现冲突时，先比较对象、定义、时间、版本和地区。边界不同就分别陈述；边界相同再比较材料是否直接、方法是否公开、是否有更正以及是否存在利益关系。
6. 当结论依赖解释、来源有直接利益、高风险决定会受影响，或不同来源冲突时，再找一份独立的二级材料交叉核验。

如果任务要求“全部”“没有”或“最新一批”，先找可以枚举候选的索引、数据库、清单、feed 或日历，并记录实际检查范围。只有普通搜索结果时，只能报告查过哪些范围，不能把“没找到”写成“没有”。

## 什么时候停止

- 核实单一事实：当前有效的一级材料直接覆盖主张，且没有会改变结论的冲突。
- 形成比较或解释：关键维度都有同口径材料，自利来源已由独立材料核验。
- 枚举候选：存在可说明的候选空间，相关入口已经检查；否则明确实际覆盖范围和未检查入口。
- 下一份来源不能改变结论、覆盖范围或不确定性时停止，不为增加链接数量继续搜索。

交回结果时，给出结论、直接链接、事件与发布或更新日期、每份材料实际证明的内容，以及未检查入口、访问失败、冲突和仍未知的部分。把事实、推断和未知分开。
