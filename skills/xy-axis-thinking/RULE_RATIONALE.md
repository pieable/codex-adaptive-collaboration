# `xy-axis-thinking` 规则理由

本文件不参与运行。该 Skill 目前缺少独立真实案例和修改日志，因此多数规则仍是“当前有明确用途但真实行为未验证”。2026-08-30 用户明确决定该 Skill 保持现状、无需修改；除非用户以后主动恢复维护，不再为补齐历史而询问，也不把正文列入优化、精简或重写候选。

## XY-01 只在当前现象不足以决定下一步时使用

- **状态：** `current-effective + unverified`
- **行为：** 用于追溯形成原因、明确目标或比较同期参照；默认内部使用，不强制展示坐标系或填模板。
- **理由：** 框架用于扩大真正会改变判断的观察维度，不应用形式压过问题本身。
- **来源：** `SKILL.md` description、“定位”；初始提交 `6a25aa8`。
- **验证：** 静态用途明确；无专门真实行为案例。
- **改变条件：** 当前对象、范围和下一步已清楚时不触发。

## XY-02 原点只补充会改变范围或下一步的 5W2H

- **状态：** `current-effective + unverified`
- **行为：** 定位对象、范围和状态；5W2H 是候选问题，不填满七项，答案不再改变判断时停止。
- **理由：** 完整表格会制造无用调查，重要的是哪些信息真正改变问题边界。
- **来源：** `SKILL.md`“原点 O”。
- **验证：** 无独立案例。
- **改变条件：** 有界审计合同明确要求逐项填写时可保留完整表格，但那不是本 Skill 默认行为。

## XY-03 x 轴分开形成原因和希望达到的目标

- **状态：** `current-effective + unverified`
- **行为：** 负方向查原因、条件、选择和关键变化；正方向明确用户希望达到的目标；自然趋势不能替代目标。
- **理由：** 只看当前症状会误判修法，只预测“会发展成什么”又会把外部趋势冒充用户选择。
- **来源：** `SKILL.md`“x 轴”；`prompt-lab/evolution-map.md` 的原因—目标—路线关系。
- **验证：** 逻辑明确；真实案例缺失。
- **改变条件：** 某一方向不会改变判断时可略过，不要求对称展开。

## XY-04 y 轴只比较相近条件和明确维度

- **状态：** `current-effective + unverified`
- **行为：** 选择可比的更成熟或较不成熟参照，说明比较维度、可比原因和材料限制；不把相对关系写成永久排名，不为对称强补两侧。
- **理由：** 泛泛“学先进、避落后”会忽略成立条件，也会把不相似对象的结果错误迁移。
- **来源：** `SKILL.md`“y 轴”。
- **验证：** 无独立真实案例。
- **改变条件：** 任务只需一侧参照时只用一侧；没有可比对象时不硬找。

## XY-05 只有两个独立维度同时需要比较时才用四象限

- **状态：** `current-effective + unverified`
- **行为：** 顺序可调整，已不改变判断的方向略过，不固定生成五段、表格、坐标图或四象限。
- **理由：** 图形是理解工具，不是交付格式；强制四象限会制造虚假对称和无行动价值分类。
- **来源：** `SKILL.md`“使用方法”“边界”。
- **验证：** 无专门真实案例。
- **改变条件：** 显式展示确实帮助用户检查两个独立维度时才绘制。
