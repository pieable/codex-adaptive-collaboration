# Working Backwards 五个问题

在团队有产品机会或原始想法，但还不能判断它是否以客户为中心、是否值得继续投入时使用。

回答五个问题：客户是谁；客户的问题或机会是什么；最重要的客户收益是什么；凭什么相信客户需要或想要它；客户体验将是什么样。答案应当来自已经取得的材料和明确推断，不用流畅措辞掩盖证据空缺。

逐项检查回答之间是否一致。客户范围改变会影响问题，问题改变会影响收益，收益应当能够在未来体验中被看见。无法回答的部分变成下一轮需要取得的证据，不在会议中凭想象补齐。

当团队能够用相互一致的答案说明为何为这类客户创造这种改变，并知道仍需验证什么时停止。五个问题帮助检查定义，不替代倾听客户、发明产品或验证方案。
