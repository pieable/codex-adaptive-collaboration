# 最近情景访谈

在需要理解客户实际怎样经历问题，而现有材料主要是概括、满意度或功能意见时使用。

请客户选择最近一次具体发生的相关事件，从事情尚未开始时讲起。沿时间追问触发原因、当时想完成的结果、实际行动、使用的工具和替代办法、出现犹豫或变通的位置、付出的代价以及最终结果。优先问“当时发生了什么”“接下来怎样做”“为什么选择这个办法”，不要把假设塞进问题，也不要让对方设计未来功能。

记录客户原话、可观察行为和发生情境；访谈者的解释另行保存。一个精彩故事不能自动代表整个市场，重复的机制和反常案例都需要后续材料判断。

当团队能够还原客户在真实情境中的行为链，知道现有办法为什么被采用、在哪里失效，以及哪些未知会改变问题定义时停止本轮访谈。需要观察环境才能判断的内容转用情境观察。

来源：[IDEO Interview](https://www.designkit.org/methods/interview.html)、[Google User Interviews](https://designsprintkit.withgoogle.com/methodology/phase1-understand/user-interviews)、[Jobs to Be Done Theory](https://www.christenseninstitute.org/theory/jobs-to-be-done/)。
