# 项目 AGENTS 示例

项目 `AGENTS.md` 既可以保存当前项目的专属规则，也可以作为 agent 进入项目时使用的稳定文件索引。只列仍然有效并会改变执行的内容；不复制能够从源码或工具直接发现的一般事实。

## 项目专属规则

- 写入这个项目时必须遵守的兼容、权限和工作方式。
- 项目自己的构建、测试、发布和真实宿主验证要求。

## 权威文件索引

| 要了解什么 | 从哪里读取 | 何时需要 |
| --- | --- | --- |
| 用户需求和成品定义 | `docs/product.md` | 判断实现结果和取舍时 |
| 系统设计与稳定接口 | `docs/architecture.md` | 修改模块接口或集成路径时 |
| 当前实现入口 | `src/...` | 开始调查或实现时 |
| 验收方式 | `tests/...`、项目测试命令 | 准备声明完成时 |
| 当前阶段状态 | `docs/current-state.md` | 接续任务或组织多阶段工作时 |

不存在的来源不要为了填表创建。一个信息已经由更权威的文件承载时，这里只写索引和适用条件，不维护第二份正文。
